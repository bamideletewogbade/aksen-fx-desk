## City-level patterns (for the pitch)

- **Funnel:** ~90% of these businesses sell via Instagram DM → WhatsApp → bank transfer/deposit. No booking, no quotes system, no order tracking. This is Ope's TFS pain multiplied across 60 businesses.
- **Payments:** "50% deposit confirms order" (Canvas Showroom), "no POD, 60% deposit" (StockFrames), "no refunds" (Wall Decor GH) — money reconciliation is manual everywhere. Paystack/Flutterwave + agent payment links is the same pitch as the TFS build.
- **Free fixes found already:** Framedinlagos fake US contact data; Nickobi lorem-ipsum + fake header contact; Chuvie demo text; frameashop.com dead domain; CMT stale listing.
- **Decision makers:** named for 8 of 60 so far (TNell ×2, Framegidi, Frame Hub, Jeggz, HNK, Fav Home ⚠, DumaDumi ⚠). Lagos/Accra incorporated businesses have LinkedIn footprints; Abuja DM-vendors mostly don't — reach them by DM/WhatsApp directly.
